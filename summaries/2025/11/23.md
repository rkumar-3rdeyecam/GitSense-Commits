    *   **Significant Change (11/23/2025, 2:21:03 PM):** A crucial logical correction was introduced in how the `recordId` is determined. The updated code correctly assigns `recordId` based on `eventName`: `eventName === "REMOVE" ? oldImage?.id?.S : newImage?.id?.S`. This ensures that `recordId` is always extracted from the appropriate image for all event types.
